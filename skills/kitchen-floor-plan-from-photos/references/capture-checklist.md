# Kitchen Floor Plan Capture Checklist

Use this checklist on every site visit so any AI agent can reliably convert photos + measurements into a clean dimensioned PDF + SVG floor plan.

## Required Photos (take all of these)

1. **Overall room from living/dining side** — standing where the open side of the kitchen is, looking into the full kitchen. Capture the island, main work zones, and both side walls if possible.
2. **Opposite overall view** — from the far end of the kitchen looking back toward the living area / sliding door.
3. **Each wall elevation** (straight-on if possible):
   - Window / sink wall
   - Range / cooking wall (or the leg that contains the range)
   - Fridge wall
   - Any remaining wall that has base or wall cabinets
4. **Island close-up** from two angles (show length, depth, overhang, and relationship to surrounding counters).
5. **Ceiling / lighting** — one shot showing can lights, vents, and any soffits.
6. **Door and window openings** — sliding glass door, hallway door, any other openings that affect layout.
7. **Appliance details** if they will stay or need exact clearances (fridge model/width, range, dishwasher).

Take photos in landscape orientation when possible. Avoid heavy flash; natural light is better.

## Required Measurements (write on the sketch or a separate note)

Always capture these, even if approximate:

- Overall room length and width (two directions)
- Island length and depth (and note which way the long axis runs)
- Base cabinet depth (usually 24") and any unusual depths
- Key linear runs of countertop (or total counter SF if already calculated)
- Window width and location relative to corners or sink
- Sliding door or other large opening width
- Fridge width and depth (or note if it is a standard 36")
- Distance from island to nearest walls / counters (clearance)
- Ceiling height (if relevant for upper cabinets or 3-D)

## Hand Sketch Requirements

- Use the one-page site visit form or a blank sheet.
- Draw the room outline roughly to proportion.
- Label the island clearly and note its orientation (long side parallel to which wall).
- Mark fridge, range, sink, dishwasher locations.
- Write all measured dimensions on the sketch with arrows or dimension lines.
- Write the property address and date on the sketch.
- Note any “keep / replace / move” decisions for major items.
- Optional but helpful: quick notes on counter SF, linear feet, or special conditions (gas line, existing electrical panel, etc.).

## Optional but High-Value Extras

- A second sketch done later at the desk with cleaned dimensions (as you did).
- Phone laser measurements or a simple floor-plan app export.
- Photos of the back of the island, under-cabinet lighting, or any awkward corners.
- Existing material notes (cabinet species/color, countertop material, flooring).

## Minimum Viable Package

If time is limited, the absolute minimum that still works well is:

- 3–4 overall and wall photos
- One clear sketch with overall dimensions + island size + appliance locations
- Property address

With the full checklist above, conversion accuracy and speed improve dramatically.
